# Repo to test your js skills

## Learn below mentioned topics

*   **Optional Chaining & Nullish Coalescing (`?.` and `??`):** Essential for safely navigating deeply nested objects and setting strict default fallbacks without bugs.
*   **Destructuring & Rest/Spread Operators (`...`):** The primary way modern JS extracts data from objects/arrays and copies or merges states cleanly without mutation.
*   **Modern Array Methods (`.map()`, `.filter()`, `.reduce()`, `.find()`):** Replaces traditional `for` loops for nearly all data manipulation and functional transformations.
*   **Promises & Async/Await:** The absolute standard for handling API calls, error handling with `try/catch`, and non-blocking asynchronous architecture.
*   **ES Modules (`import` and `export`):** The native system for structuring codebases and sharing components across different files using named and default tokens.
*   **Closures & Lexical Scope:** The core mechanism behind how functions remember variables from their parent scope (critical for state management and modern framework hooks).
*   **Modern ES6 Classes & Prototypes:** Object-oriented blueprints, constructor configurations, and memory-efficient method sharing via the prototype chain.
*   **The Event Loop:** Understanding how JavaScript schedules code execution, macro-tasks, and micro-tasks behind the scenes.
